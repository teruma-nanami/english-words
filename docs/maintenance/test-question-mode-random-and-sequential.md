# テスト出題モードの追加（ランダム／順番）

## 目的・背景

- 現在のテスト機能は単語帳を選択し、ランダムにN問出題する方式のみである
- 単語帳内の並び順（wordbook_word.order）に沿って、登録されている単語をすべて順番どおりに出題したいという要望がある
- 出題方式を「ランダム」「順番」の2モードに分け、利用者が選択できるようにする

## 利用者

- テスト機能：全ユーザー（既存のテスト機能と同じ）

## 必要な挙動

### モード選択

- テスト開始フォームで、出題モードを「ランダム」「順番」からラジオボタンで選択する
- 選択したモードに応じて、フォームの入力項目が切り替わる

### ランダムモード（既存の挙動）

- 単語帳を選択し、出題数（N問）を指定する
- 単語帳内からランダムにN問出題する

### 順番モード

- 単語帳を選択する
- 出題数・開始位置の指定はできない
- 単語帳内の並び順（wordbook_word.order）に沿って、単語帳内のすべての単語を順番どおりに出題する

## 受け入れ条件

- [ ] テスト開始フォームで「ランダム」「順番」の出題モードを選択できる
- [ ] 「ランダム」選択時は、現状と同じく単語帳選択＋出題数指定でランダムN問出題される
- [ ] 「順番」選択時は、単語帳選択のみで開始でき、出題数・開始位置の入力欄は表示されない
- [ ] 「順番」モードで、単語帳内の並び順（order）に沿って、単語帳内の全単語が出題される

## 対象外

- 順番モードの途中保存・再開機能
- 順番モードの前回開始位置の記憶機能
- 単語帳の並び順（order）自体を変更する機能
- 単語帳の新規作成・編集・削除

## 制約

- 既存の`wordbook_word.order`カラムをそのまま利用し、DBスキーマの変更は行わない
