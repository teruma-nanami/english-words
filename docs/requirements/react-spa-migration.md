# React SPA移行

## 目的・背景

- 現行はLaravelのBladeテンプレートで全画面を提供している
- フロントエンドをReact SPAに移行し、バックエンドはAPIに専念する構成へ変える
- 将来的なAuth0（Googleログイン）導入に向けた基盤を整える

## 利用者

- 全ユーザー：単語一覧・テスト
- 認証済みユーザー：単語・単語帳の管理

## 必要な挙動

### 全体
- 全ページをReactで実装する
- バックエンドはJSON APIを提供し、ReactがAPIを通じてデータを取得・送信する
- ログインページはLaravel Blade（`/login`）のまま維持する
- Tailwind CSSを導入し、モダンなデザインを実装する

### 認証連携
- 未認証で管理ページにアクセスした場合、Laravelの`/login`にリダイレクトする
- Bladeログイン後、管理ページへ戻る

### 移行対象ページ
- 単語一覧（認証状態に応じた管理導線を統合する。詳細は「単語一覧」を参照）
- テスト（単語帳選択・出題数指定・テスト実行）
- 管理：単語帳選択（`docs/maintenance/word-management-and-test-improvement.md`参照）
- 管理：単語追加
- 管理：単語編集
- 管理：単語帳追加

### 単語一覧
- 単語一覧ページは認証・未認証を問わず同一ページ（`/`）とする。管理専用の一覧ページは設けない
- ログイン中は、一覧の各単語をクリックすると単語編集ページへ遷移できる
- 未ログイン時は、単語はクリックできない

### 単語編集
- 単語編集ページから対象の単語を削除できる
- 削除時は確認ダイアログを表示し、誤操作を防ぐ

### 単語追加への導線
- グローバルメニューの「単語追加」は、単語帳選択ページへ直接遷移する

## 受け入れ条件

- [ ] 全ページがReactで表示される
- [ ] ReactからAPIを通じて単語・単語帳のデータを取得・作成・更新できる
- [ ] 未認証で管理ページにアクセスすると`/login`にリダイレクトされる
- [ ] Bladeログイン後、管理ページを操作できる
- [ ] テストページで単語帳を選択し、指定した問数でテストを受けられる
- [ ] 単語追加・編集・単語帳追加の各操作がReactから実行できる
- [ ] ログイン中に単語一覧で単語をクリックすると、単語編集ページへ遷移する
- [ ] 未ログイン時、単語一覧の単語はクリックできない
- [ ] 単語編集ページから単語を削除でき、削除前に確認ダイアログが表示される
- [ ] グローバルメニューの「単語追加」から単語帳選択ページへ直接遷移する
- [ ] Tailwind CSSでモダンなデザインが実装されている

## 対象外

- Auth0・Googleログインの導入
- 既存Bladeビューの削除

## 制約

- バックエンドのDB変更・フォーム変更は
  `docs/maintenance/word-management-and-test-improvement.md` の要件を前提とする
- ログイン画面はBladeを維持するため、SPAとBladeが一時的に共存する
